About the system

The Medicine Recommendation System is a health recommendation tool that combines a curated symptom reference with a machine-learning model (Support Vector Classifier) trained on symptom-disease data.

After recording the patient's profile and symptoms, the system suggests a possible condition along with a description, precautions, commonly used medications, diet and workout guidance.

The Medicine Recommendation System provides general information only and does not replace a consultation with a qualified healthcare professional.
